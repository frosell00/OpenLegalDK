# Contributing to OpenLegalDK

Thanks for your interest in making legal text easier to work with.

1. Open an issue describing the citation format or problem you want to address.
2. For parsing changes, add a **synthetic** legal citation example and a unit test.
3. Run `python -m unittest discover -s tests -v` before opening a pull request.
4. Keep dependencies minimal and document behavior changes in the README.
5. Avoid adding personal data, copyrighted legal database exports, or confidential client documents.

Good first contributions include adding well-defined citation formats, testing unusual whitespace and Unicode punctuation, and improving documentation.

By contributing code you agree to license your contribution under the project's MIT License.
